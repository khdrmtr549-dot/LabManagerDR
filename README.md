# مختبر — LabManager

تطبيق Android لإدارة بيانات المختبر محليًا، بواجهة عربية RTL.

## البناء على GitHub

1. ارفع محتويات هذا المجلد إلى Repository.
2. افتح Actions.
3. اختر Android Build.
4. اضغط Run workflow.
5. بعد نجاح البناء افتح Artifacts وحمّل `LabManager-debug-apk`.

## ملاحظة
هذه النسخة تبني APK عبر GitHub Actions. لا ترفع بيانات مرضى حقيقية إلى مستودع عام.
